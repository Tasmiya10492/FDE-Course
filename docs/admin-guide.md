# Administrator Guide

## Responsibilities
- Manage application configuration and secrets securely.
- Maintain database backups and verify restore procedures.
- Review user access and role assignments.
- Monitor audit events and application logs.
- Apply database migrations in the documented order.
- Keep Python dependencies and container images updated.

## Security
Grant only the permissions required for each role. Review access changes and investigate unexpected authentication failures.

Never store credentials in source code or commit them to Git.
