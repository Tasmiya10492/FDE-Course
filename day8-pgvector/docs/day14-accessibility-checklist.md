# Day 14 – Accessibility Checklist

Project: Knowledge Assistant Web UI

| No. | Accessibility check | Result |
|---|---|---|
| 1 | Every form field has a visible, associated label. | Passed |
| 2 | The question field can be reached using the keyboard. | Passed |
| 3 | The Submit button can be reached and activated using the keyboard. | Passed |
| 4 | The form can be submitted using the keyboard. | Passed |
| 5 | Keyboard focus is clearly visible. | Passed |
| 6 | The loading message is announced using an accessible status region. | Passed |
| 7 | New answers are announced through the answer region. | Passed |
| 8 | Error messages are presented with an alert role. | Passed |
| 9 | Text and controls have readable visual contrast. | Passed |
| 10 | The page layout works at different screen sizes. | Passed |
| 11 | Headings and page language are defined appropriately. | Passed |
| 12 | No browser console errors were observed during testing. | Passed |

## Conclusion

The Knowledge Assistant interface passed the manual accessibility checks performed in the browser. Keyboard navigation, visible focus, labels, status messages, responsive layout and visual contrast were checked.
