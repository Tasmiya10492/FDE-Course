# Day 14 – UX Usability Checklist

Project: Knowledge Assistant Web UI

| No. | Usability check | Result |
|---|---|---|
| 1 | The page clearly explains that users can ask questions about HR policies. | Passed |
| 2 | The question field is clearly labelled. | Passed |
